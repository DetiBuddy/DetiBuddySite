<<abstract>> Utilizador Cluster 1: Identidade id (UUID), sub_oidc (String), email_ua (String), nome (String), criado_em (DateTime) Generaliza Administrador e Estudante; 1 → 0..* Sessão (Estabelece) PostgreSQL (Tabela users / Keycloak OIDC)
Administrador Cluster 1: Identidade (Herda de Utilizador) Especializa Utilizador; 1 ..> 0..* DocumentoNormativo (Carrega) PostgreSQL (Role admin)
Estudante Cluster 1: Identidade nmec (String), curso (String), idioma (String), historico_ativo (Boolean) Especializa Utilizador; 1 ..> 1..* Inscrição; 1 ..> 1..* MensagemUtilizador (Possui) PostgreSQL (Tabela estudante / PACO API)
Sessão Cluster 1: Identidade idSessao (UUID), canalOrigem (Canal), dataInicio (DateTime), expiraEm (DateTime), ativa (Boolean) Pertence a 1 Utilizador; 1 → 0..* Conversa (Agrega) Redis (TTL curto / chave session:{id})
Conversa Cluster 1: Identidade idConversa (UUID), tituloResumo (String), criadaEm (DateTime) Pertence a 1 Sessão; 1 *-- 1..* Mensagem (Contém) PostgreSQL (Tabela conversa) + Redis cache
<<abstract>> Mensagem Cluster 1: Identidade id (UUID), conteudo (String), criada_em (DateTime), latencia_ms (Int) Contida em 1 Conversa; Generaliza MensagemUtilizador e MensagemChatbot PostgreSQL (Tabela mensagem)
MensagemUtilizador Cluster 1: Identidade tokens_in (Int) Especializa Mensagem; Possuída por Estudante PostgreSQL (Tabela mensagem_utilizador)
MensagemChatbot Cluster 1: Identidade tokens_out (Int), estado (EstadoResposta) Especializa Mensagem; 1 → 0..1 Feedback (Recebe); 1 ..> 0..* CitacaoFonte (Cita) PostgreSQL (Tabela mensagem_chatbot)
<<enum>> EstadoResposta Cluster 1: Identidade ANALISANDO_PERGUNTA, PENSANDO_RESPOSTA, CONCLUIDO, ERRO, ABORTADO Tipifica a máquina de estados do assistente conversacional Enum TypeScript / PostgreSQL ENUM
Feedback Cluster 1: Identidade idFeedback (UUID), rating (Classificacao), comentario (String), registadoEm (DateTime) Recebido por 1 MensagemChatbot PostgreSQL (Tabela feedback_auditoria)
DocumentoNormativo Cluster 2: RAG idDocumento (UUID), titulo (String), categoria (TipoDoc), orgaoEmissor (String), dataAprovacao (Date), dataValidade (Date), estado (EstadoDoc) Carregado por Administrador; 1 *-- 1..* ChunkDocumento (Particionado) PostgreSQL (Tabela documento_normativo)
ChunkDocumento Cluster 2: RAG idChunk (UUID), sequencia (Int), textoExcerto (String), embedding (Vector), artigoReferenciado (String), pagina (Int) Particionado a partir de 1 DocumentoNormativo; 1 → 0..* CitacaoFonte (Evidência) PostgreSQL com extensão pgvector
CitacaoFonte Cluster 2: RAG artigoFormal (String), documentoOrigem (String), scoreSimilaridade (Float), urlOficial (String) Evidência de 1 ChunkDocumento; Citada por MensagemChatbot Metadados no payload de resposta RAG
UnidadeCurricular Cluster 3: Académico codigoUC (String), designacao (String), sigla (String), anoLetivo (String), semestre (Int), ects (Float) 1 → 0..* Inscrição (Refere); 1 → 1..* AulaHorario (Tem); 1 → 0..* Avaliacao (Tem) PostgreSQL / PACO Open Data API
Inscrição Cluster 3: Académico anoMatricula (String), estado (EstadoInscricao), turmaPratica (String) Refere 1 UnidadeCurricular; Possuída por Estudante PACO API (Token OIDC do estudante)
AulaHorario Cluster 3: Académico diaSemana (DiaSemana), horaInicio (Time), horaFim (Time), tipologia (TipoAula), sala (String), edificio (String) Pertence a 1 UnidadeCurricular (1..*) PostgreSQL / PACO Horários
Avaliacao Cluster 3: Académico idAvaliacao (UUID), tipo (TipoAvaliacao), dataHora (DateTime), sala (String), pesoPercentual (Float) Pertence a 1 UnidadeCurricular; Monitorizada por Alerta e Calendário PostgreSQL / Moodle Calendar sync
Cantina Cluster 4: Campus nomeCantina (String), localizacaoCampus (String) 1 → 0..* EmentaDiaria (Serve) PostgreSQL / SASUA API
EmentaDiaria Cluster 4: Campus dataRefeicao (Date), refeicao (TipoRefeicao), pratoCarne, pratoPeixe, opcaoVegetariana, opcaoDieta, sopa Servida por 1 Cantina Redis (Cache TTL 24h)
ParqueEstacionamento Cluster 4: Campus nomeParque (String), lotacaoMaxima (Int), lugaresOcupados (Int), taxaOcupacao (Float), dataTelemetria (DateTime) Serviço independente de mobilidade campus Redis (Telemetria Quickload sensor campus)
ServicoAtendimento Cluster 4: Campus nomeServico (String), localizacaoBalcao (String) 1 → 0..* SenhaAtendimento (Gera) API Balcão Único / Senhas UA
SenhaAtendimento Cluster 4: Campus letraNumero (String), estado (EstadoSenha), dataEmissao (DateTime), tempoEsperaMin (Int) Gerada por ServicoAtendimento; Monitorizada por Alerta Redis (TTL curto e filas ativas)
PrevisaoMeteorologica Cluster 4: Campus dataHora (DateTime), temperaturaMin, temperaturaMax, probabilidadeChuva, condicaoCeu Serviço contextual meteorológico IPMA API aberta / Redis
SubscricaoAlerta Cluster 5: Alertas idSubscricao (UUID), tipo (TipoAlerta), canal (CanalEntrega), ativo (Boolean), criadaEm (DateTime) 1 → 1 Notificacao (Gera); Gerada por EventoCalendario; Monitoriza Avaliação e Senhas PostgreSQL / Filas Redis ARQ
Notificacao Cluster 5: Alertas idNotificacao (UUID), titulo (String), conteudo (String), dataEnvio (DateTime), estado (EstadoEntrega) Gerada por 1 SubscricaoAlerta PostgreSQL (Tabela notificacao)
EventoCalendario Cluster 5: Alertas id (UUID), tipo (TipoEvento), inicio (Date), fim (Date), descricao (String) Tipado por TipoEvento; 1 ..> 1 SubscricaoAlerta (Gera); Agenda Avaliação PostgreSQL (Tabela evento_calendario)
<<enum>> TipoEvento Cluster 5: Alertas PERIODO_LETIVO, PALESTRA, FERIADO, EXAME, OUTRO Tipologia de eventos calendarizados na universidade Enum TypeScript / PostgreSQL ENUM
