02Arquitetura

Arquitetura v2 (Fase de Elaboração) — Visão Geral do Sistema:

A solução adota uma topologia modular e desacoplada assente em microsserviços e no padrão Model Context Protocol (MCP):

  • Edge & Frontend: Proxy reverso Traefik e cliente web React PWA instalável (responsivo móvel, com suporte a modos claro/escuro).
  • Backend API: Python com FastAPI assíncrono, gerindo autenticação, sessões e streaming em tempo real via SSE (Server-Sent Events).
  • Identidade & SSO: Contentor Keycloak a operar como IdP simulado OIDC para emissão e validação estrita de tokens JWT institucionais.
  • Persistência & RAG Híbrido: PostgreSQL com extensão pgvector (combinação de similaridade vetorial com pesquisa léxica BM25) e Redis com worker assíncrono ARQ para cache e filas de tarefas.
  • Conectores MCP Desacoplados: Servidores dedicados por domínio (PACO, Moodle, SAS, M365, IPMA, Parques, Bibliotecas), comutáveis entre mock e real.
  • Soberania e Privacidade: Inferência de LLM executada no cluster Skynet do DETI, garantindo conformidade com o RGPD e total confinamento institucional dos dados.
